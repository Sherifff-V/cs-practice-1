## Различие между Git и GitHub  

* **Git** — это локальная **система контроля версий** (консольная утилита). Она работает на вашем компьютере, отслеживает изменения в файлах и хранит всю историю проекта локально.
* **GitHub** — это **облачная платформа** (веб-сервис), которая хостит репозитории Git. Она нужна для хранения кода в сети, совместной работы над проектом и обмена изменениями между разработчиками.
* **git status** - Текущее состояние рабочей дирректории
* **git diff** - Разница между рабочей дирректорией и индексом
* **git diff --staged** - Разница между индексом и последним коммитом

**Ветка в Git** — это легкий и подвижный указатель на один из коммитов
